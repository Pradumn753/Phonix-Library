⚙️ App Security Notes

  • Admin PIN is stored as SHA-256 hash.
  • Student login uses Name + Seat + unique Student PIN.
  • Student login is rate-limited and temporarily locked after repeated failures.
  • Admin session auto-locks after inactivity.
  • Encrypted backups use AES-GCM.
  • With Cloud Database configured, data is shared across devices; otherwise it remains in this browser.
